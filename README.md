# AnimeWatcher Android downloads

This public repository holds signed Android APK release assets and SHA-256 checksum files for [Anime Hub](https://anime.karammatar.com/settings). The application source repository is private and is not copied here.

Download the current verified APK from the **Android app** panel in the website's Settings page. Each release has a version-specific APK and checksum. Install a newer build as an update; do not uninstall the existing app or clear its storage.

Current release: [AnimeWatcher 1.0.2, build 18](https://github.com/KarmaSora/AnimeWatcher-Downloads/releases/tag/v1.0.2-build18).
